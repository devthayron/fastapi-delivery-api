# Projeto Delivery - FastAPI

Projeto desenvolvido com base no curso **Projeto 5 - FastAPI: API com Backend Completo - Projeto Delivery**, da Hashtag Treinamentos.

O objetivo foi praticar o desenvolvimento de uma API backend utilizando **FastAPI** e **SQLAlchemy**, aplicando os conceitos apresentados no curso e evoluindo a implementação por meio de estudos complementares e boas práticas de desenvolvimento.

Além do conteúdo apresentado no curso, foram aplicadas melhorias relacionadas à organização e modularização do projeto, utilização do padrão moderno do **SQLAlchemy 2.0**, validação e padronização dos dados de entrada e saída da API, buscando maior qualidade, organização e facilidade de manutenção.

O projeto também serviu como prática de estudo contínuo, permitindo aprofundar conceitos de desenvolvimento backend e aplicar boas práticas na construção de APIs.

## Tecnologias

* Python
* FastAPI
* SQLAlchemy 2.0
* Pydantic
* SQLite
* Alembic

## Conceitos praticados

* Desenvolvimento de APIs REST
* Organização e modularização de código
* Modelagem de dados com SQLAlchemy ORM
* Validação e padronização de dados com Pydantic
* Estruturação de schemas dos endpoints
* Autenticação e autorização de usuários
* Hash de senhas com Argon2
* Gerenciamento de sessões com SQLAlchemy
* Relacionamentos entre modelos
* Migrations com Alembic
