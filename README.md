# Projeto Delivery - FastAPI

Projeto em desenvolvimento baseado no curso **Projeto 5 - FastAPI: API com Backend Completo - Projeto Delivery**, da Hashtag Treinamentos.

O objetivo é praticar o desenvolvimento de uma API backend utilizando **FastAPI** e **SQLAlchemy**, aplicando os conceitos apresentados no curso e evoluindo a implementação através de estudos complementares e boas práticas de desenvolvimento.

Além do conteúdo apresentado no curso, estou aplicando melhorias relacionadas à organização do projeto, modularização, utilização do padrão moderno do **SQLAlchemy 2.0**, validação e padronização dos dados de entrada e saída da API, buscando maior qualidade, organização e facilidade de manutenção.

O projeto também serve como prática de estudo contínuo, permitindo aprofundar conceitos de desenvolvimento backend e aplicar boas práticas na construção de APIs.

## Tecnologias

* Python
* FastAPI
* SQLAlchemy 2.0
* Pydantic
* SQLite
* Alembic

## Conceitos praticados

* Desenvolvimento de APIs REST
* Organização e modularização de código
* Modelagem de dados com SQLAlchemy ORM
* Validação e padronização de dados com Pydantic
* Estruturação de schemas dos endpoints
* Hash de senhas com Argon2
* Gerenciamento de sessões com SQLAlchemy
* Migrations com Alembic
* Boas práticas de desenvolvimento backend

## Evoluções futuras

* Evoluir a arquitetura do projeto conforme novos conhecimentos forem adquiridos.
* Implementar autenticação e autorização de usuários.
* Adicionar novos endpoints e funcionalidades ao sistema de delivery.
* Adicionar testes automatizados.
