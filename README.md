# Projeto Delivery - FastAPI

Projeto em desenvolvimento baseado no curso **Projeto 5 - FastAPI: API com Backend Completo - Projeto Delivery** da Hashtag Treinamentos.

O objetivo é praticar o desenvolvimento de uma API backend utilizando **FastAPI** e **SQLAlchemy**, aplicando os conceitos apresentados no curso e evoluindo a implementação através de estudos complementares e boas práticas de desenvolvimento.

Além do conteúdo apresentado no curso, estou aplicando melhorias relacionadas à organização do projeto, modularização, utilização do padrão moderno do **SQLAlchemy 2.0** e estruturação de código visando maior qualidade, organização e facilidade de manutenção.

Durante o desenvolvimento, utilizo ferramentas de apoio ao aprendizado, como a **OpenAI**, para auxiliar na análise de código, entendimento de conceitos e aplicação de melhores práticas.

## Tecnologias

- Python
- FastAPI
- SQLAlchemy 2.0
- SQLite

## Conceitos praticados

- Desenvolvimento de APIs REST
- Organização e modularização de código
- Modelagem de dados com SQLAlchemy ORM
- Estruturação de backend
- Boas práticas de desenvolvimento

## Evoluções futuras

- Evoluir a arquitetura do projeto conforme novos conhecimentos forem adquiridos.
- Avaliar a utilização do **SQLModel** como uma alternativa para simplificação da camada de modelagem, aproveitando a integração com SQLAlchemy e Pydantic.
- Adicionar novas melhorias relacionadas à organização, testes e escalabilidade.
